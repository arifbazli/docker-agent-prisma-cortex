# Docs briefing tool

Answers a Prisma Cloud / Cortex Cloud question with a short briefing built only
from official documentation. Back to the [README](../README.md).

## Pipeline

```
question -> researcher (RESEARCH_MODEL) -> quote check (script) -> judge (JUDGE_MODEL) -> writer (WRITER_MODEL) -> briefing
```

The researcher fetches pages and extracts facts with quotes. A script checks each
quote against the fetched page. The judge, from a different model family, decides
whether the quote supports the fact. The writer uses supported facts only.
`MODE=agent` runs the whole flow inside docker-agent instead (root agent on
`ROUTER_MODEL`). Diagram: [architecture.md](architecture.md).

## Configs

| Config | Scope |
|---|---|
| `agents/prisma-cortex-hub.yaml` (default) | Palo Alto Networks products, focus on Prisma Cloud and Cortex Cloud |
| `agents/cortex-cloud-hub.yaml` | Cortex Cloud only |

Fetching is limited to `cortex-docs.paloaltonetworks.com`,
`docs-cortex.paloaltonetworks.com`, `docs.paloaltonetworks.com`,
`www.paloaltonetworks.com`, `docs.prismacloud.io` and `pan.dev`.

## Examples

```bash
scripts/run.sh "Why migrate from Prisma Cloud to Cortex Cloud?"
CFG=agents/cortex-cloud-hub.yaml scripts/run.sh "What does Cortex Cloud AI-SPM monitor?"
JUDGE_MODEL=gpt-oss:20b-cloud scripts/run.sh "How do I authenticate to the Cortex Cloud API?"
```

## Output and exit codes

The briefing is printed and saved to `outputs/<run>.md`;
`outputs/<run>.evidence.json` holds each fact, quote and verdict. Check the
**To confirm** items yourself. One-line results: `OUT OF SCOPE`, `NO FACTS FOUND`,
`BRIEFING FAILED` (see `logs/`).

Exit codes of `scripts/run.sh`: `0` briefing passed checks (or a valid one-line
result), `1` briefing produced but failed checks, `2` a pipeline step failed,
`64` usage.

## Docker

```bash
cp .env.example .env && printf 'HOST_UID=%s\nHOST_GID=%s\n' "$(id -u)" "$(id -g)" >> .env
mkdir -p outputs logs fetched
docker compose run --rm --build agent "Why migrate from Prisma Cloud to Cortex Cloud?"
```

Uses Ollama on the host. Prebuilt image:
`ghcr.io/arifbazli/grounded-ai-guardrails:latest`. See
[compose.yaml](../compose.yaml) to run Ollama in a container.

## Benchmark

`bench/run-all.sh` runs the questions in `bench/questions.txt` and appends one row
per question to `bench/results.tsv`.

## Tenant assistant (experimental)

Read-only questions about your own Prisma Cloud / Cortex Cloud tenants. Untested
against a live tenant. Tenant data is sent to the model provider. Fill the
`PRISMA_*` and `CORTEX_*` values in `.env` with read-only keys, then:

```bash
scripts/gen-tenant-config.sh && eval "$(scripts/prisma-login.sh)"
docker-agent run --exec --env-from-file .env agents/tenant-readonly.local.yaml "List my cloud accounts in both tenants"
```

`agents/tenant-readonly.local.yaml` is generated by `scripts/gen-tenant-config.sh`
and is not tracked in git.
