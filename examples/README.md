# Examples

Earlier experiments, kept for reference. They are not maintained, not
generated from the template, and not covered by CI.

| File | What it shows |
|---|---|
| `local.yaml` | Single agent |
| `02-file-reader.yaml` | Agent with a file-reading tool (`sandbox/`) |
| `03-team.yaml` | Small team of agents |
| `04-writer-critic.yaml` | Writer / critic loop |
| `20-pan-research.yaml` | First version of the PANW research pipeline (no prompt-injection guard; do not use for real work) |

Run from the repo root, e.g. `docker-agent run examples/local.yaml`.
